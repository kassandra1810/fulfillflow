# FulfillFlow

Backend platformy FulfillFlow — aplikacja Spring Boot 4 na Javie 25.

## Wymagania
- JDK 25
- Maven nie jest wymagany — projekt używa wrappera `./mvnw`

## Uruchomienie
```bash
cd platform-api
./mvnw spring-boot:run
```
Aplikacja startuje domyślnie na `http://localhost:8080`.

## Testy
```bash
cd platform-api
./mvnw verify
```
